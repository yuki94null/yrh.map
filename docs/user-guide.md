# yrh.map ユーザーガイド

Minecraft Java Edition 26.3でデータパックと対応リソースパックを導入する。
関数の更新は /reload、画像・フォント・シェーダーの更新は F3+T で反映する。

## 設置

/function yrh.map:debug/give_map で地図アイテムを取得する。
地面に立ち、十分な空間を確保して使用する。所有者ごとに地図1つを管理する。
固定していない地図は所有者が25ブロックより遠く離れた場合やオフライン時に撤去対象になる。

## コントローラー

地図上でスニークすると足元に表示される。

| ボタン | 右クリック | 左クリック |
|---|---|---|
| 移動 | 向いている東西南北へ | 反対方向へ |
| ホーム | 設置時の参照位置へ | 同じ |
| リロード | 描画更新 | 同じ |
| サイズ | 大きくする | 小さくする |
| 縮尺 | 広い範囲を表示 | 拡大 |

## ラジアルメニュー

地図アイテムを持ち、地図上でCtrlを押す。視点で選び、離して決定する。
選択角度は7〜30度。上から時計回りに、公開ウェイポイントの設定、公開設定、次ページ、撤去、前ページ、固定設定。
上側のランプは有効な設定を緑で示す。

## ウェイポイント

空のPnを右クリックで選択し、盤面を右クリックして配置する。スニーク右クリックで選択解除。
赤い✘で削除する。配置し直す場合は削除してから置く。
配置済みPnやアイコンを右クリックすると、その地点を中心に表示する。
Pnの左クリックで個人ピンの公開設定を切り替える。
外見欄の左クリックで既定アイコンへ戻す。既定状態でアイテムを持って右クリックすると外見を設定する。
個人ピンはサイドのページに関係なく盤面の範囲内に表示される。
公開ウェイポイント表示がオンなら他者の公開ピンも全ページ分を対象に表示する。
盤面のピンの右クリックは縮尺を維持して中心移動、左クリックは座標をチャット表示する。
コントローラー表示中は盤面ピンのクリック判定が無効になる。
公開地図では他のプレイヤーもサイド・盤面からピンへ中心移動できる。

## アイコン更新

リソースパックの textures/item に画像を置く。
ラジアル用はリソースパックのルートで generate_radial_menu_icons.py を実行する。
コントローラーの home/reload/move は32×32 PNGを直接使用する。
中央揃えの再計算は generate_controller_icons.py。PythonとPillowが必要。
ラジアル先頭画像は waypoint_visible.png、ピンの既定画像は waypoint.png。
更新後はF3+Tで読み直す。

## 確認

黒い領域は保存済み地形データを確認し、リロードボタンで描画を更新する。
操作できない表示では所有者と地図の公開設定を確認する。
構文チェックは画面表示やマルチプレイの実操作まで保証しない。更新後は個人地図と公開地図の両方で確認する。
